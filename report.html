Шаг 1 · Приложение

Простой веб-сервер на Python

$ python app.py
$ curl http://localhost:32777
from http.server import BaseHTTPRequestHandler, HTTPServer
import socket

PORT = 32777


class Handler(BaseHTTPRequestHandler):
    def do_GET(self):
        body = f"Hello, World! Answered by: {socket.gethostname()}\n"
        self.send_response(200)
        self.send_header("Content-Type", "text/plain; charset=utf-8")
        self.end_headers()
        self.wfile.write(body.encode())


if __name__ == "__main__":
    HTTPServer(("0.0.0.0", PORT), Handler).serve_forever()

Шаг 5 · Deployment

Запустил 2 копии приложения

$ kubectl apply -f deployment.yaml
$ kubectl get pods -o wide
kind: Deployment
metadata:
  name: hello-app
spec:
  replicas: 2
  selector:
    matchLabels: { app: hello-app }
  template:
    metadata:
      labels: { app: hello-app }
    spec:
      containers:
        - name: hello-app
          image: slopero/hello-app:latest
          ports:
            - containerPort: 32777
kubectl get pods -o wide
Шаг 6 · Service

Сделал общую точку входа

$ kubectl apply -f service.yaml
$ kubectl get svc
нода :30080→сервис :80→под :32777
kind: Service
metadata:
  name: hello-service
spec:
  type: NodePort
  selector: { app: hello-app }
  ports:
    - port: 80            # порт сервиса
      targetPort: 32777   # порт приложения
      nodePort: 30080     # порт на ноде
kubectl get svc
Проверка

Сервис отвечает

$ minikube service hello-service --url
$ curl http://127.0.0.1:58038
minikube service hello-service --url

Шаг 7 · Проброс портов

Открыл приложение в браузере

$ kubectl port-forward service/hello-service 8080:80
# открыть http://localhost:8080
kubectl port-forward
localhost:8080
